# Примеры — arc-anytype-bugs

## A. Триаж (фрагмент CSV)

**Вход:** строка с ID `2460017712`, тип «Производительность», критичность «Серьёзно — мешает, но есть обход».

**Действие:** одна карточка `task` с **Тип задачи = Баг**, имя «Галерея зависает на прелоадерах при открытии», статус **Задача** (бэклог).

**Не объединять** с ID `2460015810` (идея про список) — разная суть.

## B. Подхват «В работе»

**Пользователь:** перенёс «Галерея зависает на прелоадерах…» в **В работе**, пишет «возьми баг».

**Агент:**

1. `API-search-space` → `types: ["task"]` → `tip_zadachi` Баг + status «В работе».
2. `API-get-object` → шаги и обход.
3. Чинит в коде, отчитывается.
4. После «ок» → `API-update-object`, status **Готово**, в теле — «Результат: …».

## C. Тестовый отчёт

**Вход:** «Тест» / «Тестовая форма», критичность «Идея».

**Действие:** карточка `[Тест] …`, `tip_zadachi` = Баг, статус **Идея**, в теле пометка «можно архивировать». **Не** брать в работу без запроса.
