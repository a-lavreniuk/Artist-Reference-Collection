# Закрыть задачу / баг в AnyType

Финальный шаг после **git-task-finish** (или вместо него, если git не нужен): обновить или создать карточку на единой доске **Таски**.

AnyType Desktop должен быть запущен. MCP: `user-anytype`. Константы — [anytype-ids.md](references/anytype-ids.md).

## Когда выполнять

| Ситуация | Действие |
|----------|----------|
| Git-финал прошёл успешно | Обновить карточку AnyType |
| Git не требовался (только skills/docs/анализ) | Создать или обновить карточку AnyType |
| Git остановлен (тесты, конфликт, critical review) | AnyType **не трогать**, сообщить |
| Пользователь настаивает закрыть при незавершённой работе | «Готово» + в «Результат» указать, что не доделано |

## 1. Определить карточку

**Приоритет:**

1. **`object_id` из сессии** — запомнен при **anytype-task-take**.
2. **Нет `object_id`** — работа из чата → **создать** карточку (п. 4).
3. **`object_id` потерян**, но карточка из AnyType → спросить. **Не угадывать**.

## 2. Сформировать секцию «Результат»

В конец markdown-тела (не заменять описание):

```markdown
## Результат

[Ссылка на PR, если есть — первая строка]

5–10 предложений: что изменилось для пользователя, ключевые файлы, как проверить. Если неполно — отдельный абзац «что осталось».
```

- Заголовок ровно **`## Результат`**.
- PR / merge-коммит / «PR не создавался».
- Если секция уже есть — дописать или заменить содержимое под заголовком.

## 3. Обновить существующую карточку

1. `API-get-object` (`format: md`).
2. `API-update-object`:
   - `markdown` — текст + «Результат»;
   - `properties` — **только** `{ "key": "status", "select": "<tag id Готово>" }`.

**Не менять:** Cursor, Source, `tip_zadachi`, имя и прочие свойства.

## 4. Создать карточку (работа из чата)

1. **Спросить Тип задачи:** «Задача» или «Баг» (оба — `type_key: "task"`).
2. **Название** — 2–3 слова по сути.
3. **Тело:**
   - **Задача:** запрос из чата + «Результат».
   - **Баг:**

```markdown
## Описание
 ---
<описание проблемы из чата>

## Результат

<ссылка на PR + 5–10 предложений>
```

4. `API-create-object`:
   - `type_key`: **`task`** (всегда);
   - `name`, `body`;
   - `properties`:
     - `tip_zadachi` → Задача или Баг (tag id из anytype-ids);
     - `status` → Готово;
   - `source` (url) — если была ссылка в чате;
   - **Cursor не заполнять**.

**Не создавать** с `type_key: "bagi"` — устарело.

## 5. Отчёт пользователю

- название;
- Тип задачи (Задача / Баг);
- статус «Готово»;
- кратко — что в «Результат».

## 6. Связка

- Старт — **anytype-task-take**.
- Git — **git-task-finish** до этого skill.
- Порядок «закрой задачу»: git-task-finish → anytype-task-finish.

## Примеры

**Из доски:** «возьми задачу» / «возьми баг» → работа → «закрой задачу» → update по `object_id`, Готово + «Результат».

**Из чата:** спросить Задача/Баг → create `task` + `tip_zadachi` сразу в Готово.
