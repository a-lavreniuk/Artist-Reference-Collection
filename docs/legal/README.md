# Правовые тексты ARC

Черновики для публикации на лендинге (Tilda) и, при желании, в базе знаний. Это не юридическая консультация: перед включением формы и Метрики тексты лучше показать юристу.

Юрисдикция: **Россия**, Федеральный закон № 152-ФЗ «О персональных данных». GDPR в этих файлах нет.

Оператор: **физическое лицо — самозанятый** (НПД). ARC — **личный проект**, не продукт работодателя по трудовому договору.

## Что заполнить до публикации

Во всех публичных файлах одинаковые скобки:

| Плейсхолдер | Что поставить |
| --- | --- |
| `[ФИО]` | Фамилия, имя, отчество самозанятого |
| `[ИНН]` | ИНН |
| `[ГОРОД]` | Город |
| `[АДРЕС]` | Адрес для связи по 152-ФЗ (обычно адрес учёта). Если не хотите публиковать домашний — спросите юриста, не оставляйте скобки пустыми |
| `[EMAIL]` | Почта, которую будете читать: запросы субъектов ПДн, отзыв согласия, баги |
| `[URL_САЙТА]` | Канонический адрес лендинга без слэша в конце, например `https://example.tilda.ws` |
| `[URL_ФОРМЫ_ЛИДОВ]` | Адрес формы беты, когда появится |
| `[ДАТА]` | Дата публикации этой редакции, например `28 августа 2026 г.` |

Пока скобки не заменены, страницы на сайт лучше не выкладывать.

## Чеклист оператора (не для посетителей)

1. **Уведомление в Роскомнадзор.** Сбор заявок с именем, почтой и Telegram — это обработка ПДн не для личных семейных нужд. Исключение «только для себя» сюда не подходит. Нужно ли подавать уведомление оператора — вопрос к юристу; часто для такого сбора его подают.
2. **Яндекс.Метрика.** В политике и баннере заложена Метрика. В счётчике укажите срок хранения. Если включите **Вебвизор**, на страницах с формой маскируйте поля имени, почты и Telegram — иначе в записи сессии могут попасть персональные данные. В [уведомлении о cookie](landing-cookie-notice-ru.md) Вебвизор описан как опция: если его нет, удалите этот абзац.
3. **Форма беты.** Поля только: имя, почта, Telegram. Обязательный чекбокс согласия, не включённый заранее. Ссылка на `/politika`.
4. **База знаний** `arc-knowledge.tilda.ws` — отдельный сайт Tilda. Если там тоже Метрика, поставьте в её футер те же `/politika` и `/cookies`.
5. **Работодатель.** В текстах прямо сказано, что ARC не является продуктом работодателя. Если по трудовому договору или локальным актам права на ПО принадлежат компании — эти формулировки нельзя публиковать без отдельного решения.
6. **Позже:** оплата, аккаунт, облако, рассылка по 38-ФЗ — потребуют новой редакции и, для рекламы, отдельного согласия.

## Как вставлять на Tilda

1. Создайте четыре скрытые из меню страницы со слагами выше (страницы не обязаны быть в шапке).
2. В общий футер добавьте блок «Правовое» как в [landing-copy-ru.md](../landing-ru/landing-copy-ru.md).
3. Подключите стандартный блок Tilda «Уведомление о cookie» и вставьте тексты из раздела «Баннер» в `landing-consent-texts-ru.md`.
4. В Метрике включите работу **после** согласия, если конструктор это позволяет. Иначе в политике нельзя честно писать, что аналитика только по согласию.
5. В копиях лендинга в футере уже стоят слаги `/politika`, `/cookies`, `/usloviya`, `/politika-arc`. На Tilda создайте страницы с теми же слагами.
