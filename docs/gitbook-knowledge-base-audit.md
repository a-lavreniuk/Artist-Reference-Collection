## Расхождения с кодом

### 1. «Всегда скрыто» — дока отрицает то, что есть в UI

**Настройки → Шаблон деталки:** «Отдельного режима «Всегда скрыто» нет.»

В коде три режима: **Видно всегда**, **Всегда скрыто**, **Скрыто если пусто** (`FIELD_VISIBILITY_LABELS` в `detailCardTemplate.ts`, редактор `DetailTemplateEditor.tsx`).

Это единственное явное противоречие этой сверки.

### 2. Клавиши J и K у аннотаций перепутаны

В GitBook: `J` — предыдущая, `K` — следующая.

В `shortcutRegistry.ts`: `J` — **Следующая аннотация**, `K` — **Предыдущая аннотация**.

### 3. Мудборд по-прежнему без своей страницы

Есть абзац в «Организация» и в «Знакомстве с интерфейсом». Нет главы: вкладка, ПКМ добавить/убрать, чем отличается от коллекции (кроме двух предложений).

### 4. URL в приложении

Кнопка «База знаний ARC» всё ещё `https://arc-app.gitbook.io/arc-app-docs/`, не `support` и не `arc-knowledge-base`.

## Что всё ещё тонко (не ломает сценарий)

- Копирование настроек: не перечислено, какие поля/метки/коллекции переносятся.
- Видео: нет клавиш `[` `]` и сохранения кадра (`Shift+S` в реестре), только «копирование кадра».
- Горячие клавиши: не полный справочник (это сознательно).
- Установка: нет прямой ссылки на GitHub/релиз на странице установки (ссылка есть в «Полезных ссылках»).
- История: не расписаны типы событий и очистка журнала.

## Итог задачи

Сверка пользовательской документации с кодом `main` (`eace5df`) завершена. GitBook правили вы; в репозитории остаётся этот отчёт.

**Документация в целом совпадает с приложением.** Закрыты ложные сценарии (полноэкран, «О приложении», фильтры, библиотека-контейнер, скриншоты, имена настроек) и добавлены недостающие главы (аннотации, категории и метки, корзина, история, статистика, отдельное окно, копирование настроек).

1. Вернуть в шаблон режим **«Всегда скрыто»** — в UI он есть.
2. Поменять местами **J** и **K** на странице аннотаций.
3. Отдельная страница мудборда.
4. В приложении сменить URL базы знаний с `arc-app-docs` на актуальный `support`.
