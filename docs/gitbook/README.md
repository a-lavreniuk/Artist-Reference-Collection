# ARC — база знаний

ARC — локальный менеджер визуальных референсов. Приложение помогает собирать изображения и видео, организовывать библиотеку и быстро находить нужные материалы.

## С чего начать

**Я впервые использую ARC** → Начало работы

**Мне нужно добавить материалы** → Сбор материалов

**Мне нужно организовать библиотеку** → Организация

**Мне нужно найти материал** → Поиск

**Мне нужно посмотреть или открыть файл** → Просмотр

**Мне нужно изменить поведение ARC** → Настройки

**Мне нужна помощь** → Справка

## Основные возможности

ARC объединяет сбор материалов, каталогизацию и поиск в одной локальной библиотеке. Исходные файлы остаются обычными файлами на компьютере, а карточки, коллекции, метки и пользовательские поля отвечают за их организацию внутри ARC.

AI-поиск позволяет искать материалы по текстовому описанию или визуальному сходству после установки модели и индексации библиотеки.
