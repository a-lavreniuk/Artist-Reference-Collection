# Справка

В разделе «Справка» находятся материалы, которые помогают решить проблему, найти дополнительную информацию или сообщить разработчикам об ошибке.

## В этом разделе

* Сообщить о проблеме — отправка сообщения об ошибке или предложении.
* Частые вопросы — ответы на типовые вопросы по работе ARC.
* Полезные ссылки — официальные и рабочие ресурсы проекта.
* О приложении — сведения о текущем приложении и версии.
