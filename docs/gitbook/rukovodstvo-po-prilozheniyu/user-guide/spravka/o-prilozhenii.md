# О приложении

На странице «О приложении» отображается информация об установленной версии ARC и другие сведения, которые приложение предоставляет для идентификации сборки.

\[скриншот: окно «О приложении»]

## Версия приложения

При обращении в поддержку или сообщении об ошибке указывайте версию ARC. Это важно, потому что поведение функций может отличаться между версиями.

## Когда проверять версию

Проверьте версию перед созданием отчёта о проблеме, особенно если ошибка связана с недавно обновлённой функцией. Версию также полезно указать, если вы сравниваете поведение ARC на разных компьютерах.
