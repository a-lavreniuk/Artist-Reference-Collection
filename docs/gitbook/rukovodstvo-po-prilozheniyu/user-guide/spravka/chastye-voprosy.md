# Частые вопросы

## Можно ли использовать ARC без AI?

Да. Обычный поиск, фильтры, коллекции, метки и просмотр материалов не требуют AI-модели.

## Где находятся мои файлы?

Файлы библиотеки находятся в папке, указанной в настройках библиотеки. ARC работает с локальным файловым путём.

## ARC автоматически синхронизирует библиотеку с облаком?

Нет. Если библиотека находится в папке Google Drive, OneDrive, Яндекс Диска или другого сервиса, синхронизацией занимается соответствующий облачный клиент.

## Почему «AI Семантика» недоступна?

Проверьте, включён ли AI-поиск, установлена ли модель и проиндексирована ли библиотека. Без готового индекса семантический поиск работать не может.

## Нужно ли индексировать библиотеку после установки модели?

Да. Установка модели и индексация — разные этапы. Модель предоставляет механизм анализа, а индекс содержит результаты анализа материалов библиотеки.

## Чем отличается коллекция от метки?

Коллекция объединяет карточки в логическую группу. Метка описывает характеристику карточки. Одна карточка может одновременно находиться в нескольких коллекциях и иметь несколько меток.

## Чем отличается файл от карточки?

Файл — физический объект на диске. Карточка — объект ARC, который представляет этот файл и содержит данные для его организации и поиска.

## Что делать с точным дубликатом при импорте?

ARC открывает диалог с вариантами: пометить совпадение как не дубликат, заменить исходник из системы или не импортировать файл.

## Можно ли искать изображения по их содержимому?

Да, если настроен AI-поиск. Для текстового описания используется «AI Семантика», а для поиска по визуальному примеру — «Похожие изображения».

## Можно ли использовать одну карточку в нескольких проектах?

Да. Добавьте карточку в несколько коллекций вместо создания нескольких физических копий одного файла.
