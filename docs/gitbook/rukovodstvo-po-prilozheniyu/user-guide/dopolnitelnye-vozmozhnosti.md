# Дополнительные возможности

Этот раздел оставлен для функций, которые не относятся к основному циклу «сбор → организация → поиск → просмотр».

На текущем этапе в пользовательское руководство не добавляются функции, наличие которых не подтверждено актуальной реализацией ARC. Это сделано намеренно: устаревшее описание хуже, чем отсутствие инструкции, поскольку пользователь может принять его за действующую механику.

Если в актуальной версии ARC появляются дополнительные пользовательские возможности, их следует описывать здесь после проверки интерфейса и поведения функции.
