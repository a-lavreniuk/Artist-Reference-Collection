# AI-поиск

Настройки AI-поиска определяют, используется ли локальный AI, какая модель установлена и где выполняются вычисления.

\[скриншот: настройки AI-поиска]

## Включение AI

Включите AI-поиск, чтобы использовать «AI Семантику» и «Похожие изображения». Без активной модели и индекса эти режимы не смогут полноценно работать.

## Модель

Выберите модель, соответствующую вашему компьютеру и требованиям к качеству. Подробное сравнение находится в [Моделях](../search/ai-poisk/modeli.md).

## Режим выполнения

Выберите CPU или GPU, если текущая версия приложения предоставляет такой выбор. Режим определяет вычислительное устройство, но не меняет сам алгоритм поиска.

## Индексация

После установки модели запустите индексацию библиотеки. Без индекса ARC не сможет сопоставлять запросы с изображениями библиотеки.

## Изменение модели

После смены модели проверьте состояние индекса. Если индекс был построен другой моделью, может потребоваться повторная индексация.
