# Скриншоты

Раздел настроек «Скриншоты» содержит параметры встроенного механизма создания снимков экрана.

\[скриншот: настройки скриншотов]

Здесь следует настраивать параметры, связанные с получением и сохранением снимков. Конкретные значения зависят от доступных элементов текущей версии ARC.

Если скриншот не создаётся или сохраняется не так, как ожидается, сначала проверьте эти настройки, затем убедитесь, что назначенное сочетание клавиш не конфликтует с другой программой.

Подробнее о самом сценарии создания снимка см. Скриншоты.
