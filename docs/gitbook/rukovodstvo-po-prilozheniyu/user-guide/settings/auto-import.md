# Автоматический импорт

Автоматический импорт предназначен для сценария, когда материалы сначала попадают в определённую папку, а затем должны автоматически появляться в библиотеке ARC.

\[скриншот: настройки автоматического импорта со списком отслеживаемых папок]

## Принцип работы

Вы задаёте папку или папки, которые ARC должен отслеживать. Когда в них появляются новые подходящие файлы, приложение обнаруживает их и запускает обычную процедуру импорта.

Автоматический импорт особенно удобен для постоянного потока материалов: например, если браузер, скриншотер или другое приложение сохраняет новые изображения в одну папку.

## Настройка

1. Откройте «Настройки → Автоматический импорт».
2. Включите функцию.
3. Добавьте папку, которую необходимо отслеживать.
4. Проверьте, что папка доступна ARC.
5. Оставьте ARC запущенным, когда хотите получать материалы автоматически.

## Дубликаты

Автоматический импорт использует правила импорта ARC. Поэтому точный дубликат не должен незаметно создавать второй идентичный материал: при обнаружении совпадения применяется механизм обработки дубликатов.

## Важное ограничение

Автоматический импорт работает с файлами, которые появляются в отслеживаемых папках. Он не предназначен для синхронизации содержимого произвольных каталогов с библиотекой. Если файл уже находится в библиотеке и не является новым объектом импорта, автоматический импорт не должен рассматриваться как механизм обновления всей структуры библиотеки.
