# Автотегирование

Автотегирование предназначено для автоматического назначения меток материалам на основе анализа их содержимого.

\[скриншот: настройки автотегирования]

## Когда использовать

Функция полезна в большой библиотеке, где ручное назначение одинаковых характеристик каждому материалу занимает много времени. Автоматические метки можно использовать как первый слой организации, а затем проверять и корректировать их вручную.

## Что важно учитывать

Автотегирование зависит от качества используемого анализа. Автоматически назначенную метку не следует считать гарантированно правильной для каждого изображения.

Если функция требует AI-модель, сначала убедитесь, что соответствующая модель установлена и доступна. При изменении настроек AI проверьте, не влияет ли это на работу автотегирования.

## Проверка результатов

После массового автотегирования рекомендуется проверить выборку карточек. Если система регулярно назначает нежелательные метки, скорректируйте настройки или удалите ошибочные значения вручную.
