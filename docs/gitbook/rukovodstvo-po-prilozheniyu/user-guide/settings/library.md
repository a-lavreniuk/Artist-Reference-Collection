# Библиотека

Настройки библиотеки содержат физическое расположение рабочей папки и связанные с ним действия.

\[скриншот: раздел «Библиотека» с указанным путём]

## Путь к библиотеке

Путь показывает, где физически расположены данные текущей библиотеки. Это обычный путь файловой системы.

## Открыть папку в проводнике

Используйте действие открытия папки, если нужно посмотреть содержимое библиотеки через проводник Windows.

## Изменение расположения

Если нужно использовать другой каталог, измените расположение библиотеки в соответствии с возможностями текущей версии ARC. Перед переносом убедитесь, что операции импорта и обработки завершены.

Если папка находится в каталоге облачного сервиса, ARC по-прежнему работает с локальным путём. Синхронизацию выполняет облачный клиент.

Не удаляйте и не переименовывайте внутренние файлы библиотеки вручную, если не понимаете их назначения: это может нарушить связь карточек с данными.
