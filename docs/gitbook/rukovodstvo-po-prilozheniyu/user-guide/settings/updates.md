# Обновления

Раздел «Обновления» отвечает за проверку доступности новой версии ARC и действия, связанные с обновлением приложения.

\[скриншот: раздел настроек «Обновления»]

Используйте проверку обновлений, если хотите убедиться, что установлена актуальная версия. Если доступна новая версия, следуйте предложенному приложением сценарию обновления.

Перед обновлением рекомендуется завершить длительные операции, особенно импорт и индексацию AI. Это уменьшает риск прерывания фоновой обработки.

После обновления проверьте важные для вашей работы функции, особенно если новая версия меняет формат данных или поведение AI-поиска.
