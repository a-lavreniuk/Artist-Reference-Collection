# Уведомления

Настройки уведомлений определяют, какие события ARC должны сопровождаться уведомлением.

\[скриншот: раздел «Уведомления»]

Используйте уведомления для фоновых или длительных операций, состояние которых не всегда удобно отслеживать непосредственно в интерфейсе. Если уведомления мешают, отключите ненужные категории, сохранив сообщения, которые действительно помогают контролировать работу приложения.

При диагностике проблемы временное включение уведомлений может помочь понять, на каком этапе остановилась операция.
