# Шаблон деталей

Шаблон деталей определяет, какие данные и в каком порядке показываются в панели «Детали» карточки.

\[скриншот: настройки шаблона деталей]

## Зачем настраивать шаблон

У разных библиотек может быть разный набор информации, который пользователь хочет видеть первым. Настройка шаблона позволяет адаптировать панель к рабочему процессу и не держать перед глазами редко используемые сведения.

## Что меняется

Изменение шаблона касается представления данных в карточке. Оно не изменяет сам исходный файл и не удаляет сохранённые метаданные.

Если пользовательские поля используются в библиотеке, их отображение должно рассматриваться вместе со структурой этих полей.

## Рекомендуемый подход

Сначала оставьте в шаблоне основные сведения, которые вы проверяете при каждом просмотре карточки. Дополнительные данные имеет смысл размещать ниже или скрывать, если они нужны только периодически.
