# Настройки

Настройки ARC разделены по назначению. Большинство параметров применяется к приложению сразу или после изменения соответствующего значения.

\[скриншот: окно «Настройки» со списком разделов]

## Разделы настроек

* **Общие настройки** — внешний вид и базовое поведение приложения.
* **Шаблон деталей** — настройка состава и порядка данных, отображаемых в деталях карточки.
* **Скриншоты** — параметры встроенного создания снимков экрана.
* **Уведомления** — поведение уведомлений ARC.
* **Горячие клавиши** — справочник доступных сочетаний клавиш.
* **Библиотека** — расположение и связанные с ним параметры библиотеки.
* **Автоматический импорт** — отслеживание папок и автоматическое добавление файлов.
* **Браузерное расширение** — параметры связи ARC с расширением браузера.
* **Обновления** — проверка и установка новых версий.
* **AI-поиск** — модель, режим выполнения и подготовка AI-индекса.
* **Автотегирование** — параметры автоматического назначения меток.

Настройки не заменяют рабочие разделы приложения: например, коллекции создаются в организации, а не в настройках. В настройках задаётся поведение самого механизма.
