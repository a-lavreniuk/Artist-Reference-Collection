# Горячие клавиши

Раздел «Горячие клавиши» содержит справочник сочетаний клавиш, доступных в ARC.

\[скриншот: список горячих клавиш в настройках]

Сочетания сгруппированы по назначению: навигация, импорт, поиск, скриншоты и обратная связь.

## Как работают сочетания

Горячие клавиши работают, когда окно ARC находится в фокусе. Если сочетание не срабатывает, сначала убедитесь, что активным является окно ARC, а не другое приложение.

Некоторые сочетания являются системными для ARC и не предназначены для переназначения. Страница настроек используется как справочник актуальных комбинаций.

## Сообщить о проблеме

Для открытия формы «Сообщить о проблеме» используется сочетание `Ctrl+Shift+B`. Оно удобно, если нужно быстро передать информацию о найденной проблеме без поиска соответствующего пункта меню.

Перед отправкой сообщения подготовьте описание действия, ожидаемый результат и фактическое поведение. Подробнее см. [Сообщить о проблеме](../spravka/report-problem.md).
