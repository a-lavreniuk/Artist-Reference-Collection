# Известные проблемы

Список известных проблем должен отражать только актуальные ограничения конкретной версии ARC.

Если проблема уже описана в этом разделе, сначала проверьте, совпадает ли ваша версия приложения и сценарий воспроизведения. Повторное сообщение всё равно может быть полезно, если фактическое поведение изменилось.

Не переносите в этот список старые проблемы автоматически после обновления. Каждое ограничение необходимо перепроверять на актуальной сборке.
