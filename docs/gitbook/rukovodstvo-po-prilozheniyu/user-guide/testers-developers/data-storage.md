# Где хранятся данные

ARC использует файловую систему для хранения библиотеки. Для диагностики важно различать исходные медиафайлы и данные, которые описывают карточки и результаты AI-анализа.

Рабочий путь библиотеки отображается в настройках. При расследовании проблемы сначала зафиксируйте этот путь и состояние файла, с которым воспроизводится ошибка.

После AI-индексации результаты анализа сохраняются в JSON-файлах рядом с исходными данными, связанными с материалами библиотеки. Эти файлы являются техническими данными приложения и не предназначены для ручного редактирования.

Если библиотека размещена в облачной папке, фактическое состояние файлов зависит также от клиента соответствующего облачного сервиса.
