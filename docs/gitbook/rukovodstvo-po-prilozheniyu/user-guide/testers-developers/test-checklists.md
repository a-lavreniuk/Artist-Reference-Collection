# Чек-листы тестирования

Чек-листы помогают проверять функции одинаково после изменений и обновлений.

## Базовый smoke-тест

* Запустить ARC.
* Создать новую библиотеку.
* Открыть существующую библиотеку.
* Импортировать изображение.
* Импортировать видео.
* Открыть карточку.
* Перейти между карточками.
* Добавить карточку в коллекцию.
* Назначить метку.
* Изменить пользовательское поле.
* Выполнить обычный поиск.
* Применить фильтр.
* Открыть исходный файл.
* Проверить настройки.

## AI smoke-тест

* Включить AI.
* Установить модель.
* Запустить индексацию.
* Выполнить семантический запрос.
* Выполнить поиск похожего изображения.
* Проверить изменение результата при изменении точности.
* Проверить поведение при отсутствии индекса.

## Импорт и дубликаты

* Импортировать новый файл.
* Повторно импортировать точный дубликат.
* Проверить все варианты решения в диалоге дубликата.
* Проверить поведение после выбора сохранения или удаления исходного файла.

Результат каждого теста фиксируйте с указанием версии ARC и условий окружения.
