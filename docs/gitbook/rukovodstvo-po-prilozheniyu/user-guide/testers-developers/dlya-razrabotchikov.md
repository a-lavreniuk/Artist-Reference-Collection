# Для разработчиков

Эта страница предназначена для технической документации проекта ARC.

## Области документации

Здесь должны быть описаны структура проекта, формат данных библиотеки, импорт, автоматический импорт, браузерное расширение, метки, пользовательские поля, шаблоны, поисковый индекс, AI-модели, индексация, embeddings, дубликаты, просмотр, настройки, логирование, сборка и релизы.

## AI-индекс

После индексации результаты анализа изображения сохраняются в JSON рядом с исходным материалом.

При смене AI-модели необходимо учитывать совместимость существующих embeddings. Может потребоваться повторная индексация.

## Совместимость данных

Изменения формата данных библиотеки должны сопровождаться миграцией или другой процедурой сохранения совместимости.

## Диагностика

При исследовании ошибки фиксируйте версию ARC, операционную систему, выбранную модель, CPU/GPU режим, размер библиотеки, действие, вызвавшее проблему, воспроизводимость и доступные логи.
