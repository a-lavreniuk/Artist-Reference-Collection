# AI-поиск для тестеров

При тестировании AI-поиска проверяйте отдельно установку модели, индексацию, текстовый поиск и поиск по изображению.

## Базовый сценарий

1. Создать или открыть тестовую библиотеку.
2. Установить выбранную модель.
3. Проиндексировать библиотеку.
4. Выполнить несколько текстовых запросов в «AI Семантике».
5. Выполнить поиск по изображению в «Похожих изображениях».
6. Повторить сценарий на CPU и GPU, если оба режима доступны.

## Что фиксировать

В отчёте указывайте модель, вычислительное устройство, количество материалов в библиотеке и характер запроса. Для проблем с результатами сохраняйте конкретный запрос и примеры изображений, на которых ошибка воспроизводится.

Если движок сообщает, что библиотека не проиндексирована, это отдельный сценарий ошибки подготовки индекса, а не проблема качества результата поиска.
