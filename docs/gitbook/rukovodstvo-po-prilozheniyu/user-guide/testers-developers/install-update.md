# Установка и обновление

Тестовая установка должна выполняться на отдельном тестовом окружении, если проверка предполагает риск изменения библиотеки или системных настроек.

Перед обновлением зафиксируйте версию ARC и сценарий, который необходимо проверить. После обновления повторите тот же сценарий и сравните фактическое поведение.

При проверке обновления отдельно тестируйте: запуск приложения, открытие существующей библиотеки, импорт, просмотр, организацию карточек, обычный поиск, AI-поиск и настройки, если эти функции затрагивались изменением.

Не используйте для тестов единственную копию рабочей библиотеки без понимания последствий операций удаления и изменения данных.
