# DevTools и логи

DevTools и логи используются для технической диагностики проблем, которые нельзя описать только через пользовательский интерфейс.

\[скриншот: DevTools или окно логов]

При сборе диагностической информации сначала воспроизведите проблему, затем зафиксируйте момент возникновения ошибки и соответствующие сообщения в логах.

Не изменяйте технические данные библиотеки вручную ради устранения ошибки без понимания их назначения. Для отчёта лучше сохранить исходное состояние и передать разработчику контекст воспроизведения.

В отчёте указывайте версию ARC, операционную систему, последовательность действий и релевантный фрагмент лога. Не включайте в публичный отчёт содержимое конфиденциальных файлов или персональные данные.
