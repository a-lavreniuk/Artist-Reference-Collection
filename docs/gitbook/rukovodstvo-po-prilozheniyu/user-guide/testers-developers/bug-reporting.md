# Сообщение о багах

Хороший баг-репорт должен позволять другому человеку повторить проблему без дополнительных предположений.

## Структура отчёта

**Окружение:** версия ARC, версия Windows, при необходимости сведения о CPU/GPU.

**Предусловия:** библиотека, модель AI, режим CPU/GPU и другие условия, необходимые для воспроизведения.

**Шаги:** последовательность действий от чистого состояния до ошибки.

**Ожидаемый результат:** что приложение должно было сделать.

**Фактический результат:** что произошло на самом деле.

**Воспроизводимость:** всегда, иногда или один раз.

**Вложения:** скриншоты, логи или небольшой тестовый файл, если они необходимы для диагностики.

## Для AI-проблем

Обязательно укажите модель и состояние индекса. Для проблем качества укажите конкретный запрос и несколько примеров неправильных результатов. Для проблем производительности укажите режим CPU/GPU и объём библиотеки.
