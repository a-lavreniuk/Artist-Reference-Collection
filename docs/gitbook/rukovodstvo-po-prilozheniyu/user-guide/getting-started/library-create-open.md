# Создание и открытие библиотеки

Библиотека определяет рабочую область ARC и папку, в которой приложение хранит файлы и связанные с ними данные. Это физическая основа каталога: карточки, коллекции и метки работают поверх содержимого библиотеки.

## Создание библиотеки

При создании библиотеки выберите папку, которая будет использоваться ARC для хранения материалов. Перед выбором убедитесь, что это подходящее постоянное расположение и на диске достаточно свободного места.

\[скриншот: диалог создания библиотеки с выбором папки]

После создания библиотека становится активной. Можно сразу перейти к импорту материалов.

## Открытие существующей библиотеки

Если библиотека уже существует, используйте команду открытия библиотеки и укажите её папку. После открытия ARC считывает доступные данные и показывает её содержимое.

Не следует одновременно создавать несколько библиотек поверх одной и той же папки. Если нужно разделить материалы, создайте отдельные библиотеки в разных папках.

## Где физически находятся материалы

Путь библиотеки можно посмотреть в настройках библиотеки. Там же доступно открытие соответствующей папки в проводнике.

Важно различать библиотеку и коллекцию. Библиотека связана с физическим расположением данных, а коллекция является логической группой карточек внутри ARC. Перемещение карточки между коллекциями не перемещает файл на диске.

## Библиотека в облачной папке

ARC не предоставляет собственной сетевой синхронизации. Если папка библиотеки расположена внутри Google Drive, OneDrive, Яндекс Диска или другого сервиса, синхронизацию выполняет этот сервис.

Для надёжной работы убедитесь, что файлы библиотеки доступны локально, если используемый сценарий облачного сервиса предусматривает режим «только онлайн».
