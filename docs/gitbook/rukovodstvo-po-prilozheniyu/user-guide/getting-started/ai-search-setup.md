# Настройка AI-поиска

AI-поиск не работает сразу после установки ARC: сначала нужно подготовить локальную AI-модель и индекс библиотеки. Настройка выполняется один раз для выбранной конфигурации, после чего поиск можно использовать в обычной работе.

## Шаг 1. Включите AI-поиск

Откройте настройки ARC и перейдите в раздел «AI-поиск». Включите использование AI и выберите модель, которую хотите установить.

\[скриншот: настройки «AI-поиск» с выбором модели]

## Шаг 2. Установите модель

ARC предлагает несколько моделей с разным балансом скорости, требований к оборудованию и качества поиска. Если вы не уверены, с чего начать, используйте модель среднего уровня, а затем при необходимости измените конфигурацию.

Установка модели требует загрузки её файлов и свободного места на диске. Размер и время установки зависят от выбранной модели.

## Шаг 3. Выберите CPU или GPU

После установки модели можно выбрать устройство, на котором выполняется анализ. GPU обычно значительно ускоряет работу тяжёлых моделей при наличии совместимой видеокарты. CPU не требует GPU, но обработка может занимать больше времени.

Выбор устройства не меняет принцип работы поиска: он определяет способ выполнения одной и той же AI-модели.

## Шаг 4. Проиндексируйте библиотеку

Установленной модели недостаточно. ARC должен обработать изображения библиотеки и создать индекс. Запустите индексацию и дождитесь её завершения.

Во время индексации можно продолжать пользоваться приложением, однако на больших библиотеках процесс может заметно нагрузить компьютер.

## Шаг 5. Проверьте поиск

После индексации откройте поиск и попробуйте несколько запросов в режиме «AI Семантика». Для проверки используйте разные формулировки, например описания объекта, сцены и визуальных признаков.

Если нужен поиск по визуальному образцу, используйте режим «Похожие изображения».

## Если AI-поиск недоступен

Если вкладка «AI Семантика» видна, но отключена, проверьте настройку AI, наличие установленной модели и состояние индекса библиотеки. Если библиотека не проиндексирована, AI-движок не сможет выполнить семантический поиск.

Подробные сведения о моделях, индексации и точности поиска приведены в разделе «AI-поиск».
