# Установка и первый запуск

ARC устанавливается как обычное настольное приложение. После запуска приложение открывает рабочее пространство библиотеки либо предлагает создать или открыть библиотеку, если она ещё не выбрана.

На первом запуске не требуется сразу импортировать всю коллекцию. Рекомендуется сначала создать небольшую рабочую библиотеку и проверить основной сценарий: импортировать несколько файлов, открыть карточку, добавить метку и выполнить поиск.

\[скриншот: первое окно ARC после установки]

## Первый запуск

После запуска проверьте, что приложение открывается без ошибок и доступно окно библиотеки. Если библиотека ещё не создана, перейдите к созданию новой библиотеки.

Если ARC предлагает пройти ознакомительный тур, его можно пройти сразу или повторить позднее из общих настроек.

## Что проверить перед массовым импортом

Перед импортом большого объёма материалов полезно убедиться в трёх вещах:

1. Вы выбрали правильную папку библиотеки.
2. На диске достаточно свободного места для копий импортируемых файлов.
3. Вы понимаете, где будут находиться физические файлы библиотеки.

ARC работает с локальными файлами. Если библиотека находится в папке облачного сервиса, синхронизацию этой папки выполняет сам облачный сервис.

## Если ARC уже установлен

При последующих запусках отдельная настройка установки не требуется. Откройте существующую библиотеку или создайте новую, если хотите вести отдельный набор материалов.
