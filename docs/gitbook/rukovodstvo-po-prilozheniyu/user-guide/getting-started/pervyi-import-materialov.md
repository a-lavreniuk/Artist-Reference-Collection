# Первый импорт материалов

Самый простой способ начать работу с ARC — добавить несколько изображений или видео через ручной импорт.

Выберите файлы для импорта. ARC скопирует их в рабочую папку библиотеки и создаст для них карточки.

\[скриншот: окно выбора файлов для импорта]

После копирования ARC предлагает выбрать, что делать с исходным файлом: оставить его на прежнем месте или удалить. Если вы не уверены, нужен ли исходник, оставьте его.

## Если найден точный дубликат

При обнаружении точного дубликата ARC открывает отдельное окно с вариантами дальнейшего действия:

* отметить материал как не дубликат;
* заменить источник из системы;
* не импортировать файл.

\[скриншот: диалог обнаружения точного дубликата]

Если материал уже есть в библиотеке и новая копия не нужна, выберите «не импортировать файл».

Подробнее о полном процессе импорта — в разделе [Добавление файлов](../collecting/add-files.md).
