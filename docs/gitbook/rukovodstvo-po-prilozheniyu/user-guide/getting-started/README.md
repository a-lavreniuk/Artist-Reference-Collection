# Начало работы

Если ARC запускается впервые, последовательно выполните шесть действий: установите приложение, создайте библиотеку, добавьте первые материалы, проверьте основные настройки, при необходимости настройте AI-поиск и выполните первый рабочий сценарий.

## В этом разделе

* Установка и первый запуск — запуск приложения и базовые действия после установки.
* Создание и открытие библиотеки — выбор рабочей библиотеки и папки её хранения.
* Первый импорт материалов — добавление первых изображений и видео.
* Первоначальная настройка — параметры ARC, которые имеет смысл проверить перед постоянной работой.
* Настройка AI-поиска — установка модели и подготовка библиотеки к смысловому поиску.
* Первый рабочий сценарий — пример полного цикла от добавления материала до его поиска.

\[скриншот: экран ARC после первого запуска с предложением создать или открыть библиотеку]

### Если библиотека уже существует

Не создавайте новую библиотеку только ради повторного запуска. Используйте команду открытия библиотеки и укажите существующую рабочую папку.

### Если AI-поиск пока не нужен

AI-функции можно не настраивать сразу. Обычный поиск, фильтры, коллекции и метки работают независимо от AI-индекса. Настроить AI-поиск можно позднее через настройки.
