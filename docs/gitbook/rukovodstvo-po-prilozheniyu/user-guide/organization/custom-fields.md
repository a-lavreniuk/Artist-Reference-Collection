# Пользовательские поля

Пользовательские поля позволяют хранить в карточках дополнительную информацию, которой нет среди стандартных данных ARC.

Они полезны, когда вы хотите каталогизировать материалы по собственной схеме: например, хранить статус работы, внутренний идентификатор, источник или другую информацию, которую нужно видеть и искать вместе с карточкой.

\[скриншот: пользовательские поля в панели деталей]

## Когда использовать пользовательское поле

Используйте поле, если значение является свойством самого материала и должно храниться вместе с карточкой.

Для группировки материалов лучше использовать коллекции. Для коротких повторяющихся признаков — метки. Для дополнительных структурированных данных — пользовательские поля.

## Создание поля

Создайте пользовательское поле в соответствующем интерфейсе организации и задайте ему понятное название. После этого поле становится доступно карточкам в соответствии с настройками ARC.

\[скриншот: создание пользовательского поля]

## Заполнение поля

Откройте карточку и перейдите к деталям. Найдите пользовательское поле и введите нужное значение. Изменение значения относится к данным карточки и не изменяет физический файл.

## Как не усложнить структуру

Не создавайте отдельное поле для каждого варианта одного и того же признака. Если значение выбирается из небольшого набора повторяющихся признаков, метки обычно подходят лучше.

Если пользовательское поле нужно только для одного проекта и больше нигде не используется, подумайте, не будет ли проще хранить эту информацию в самой проектной коллекции.
