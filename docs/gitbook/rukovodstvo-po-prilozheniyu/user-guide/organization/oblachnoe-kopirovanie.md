# Облачное копирование

ARC не предоставляет отдельную встроенную синхронизацию библиотеки между компьютерами.

Библиотеку можно разместить в папке, которую синхронизирует сторонний сервис, например Google Drive, OneDrive или Яндекс Диск. В таком сценарии облачный сервис отвечает за копирование и синхронизацию файлов, а ARC — за работу библиотеки.

> Не выполняйте конфликтующие изменения одной библиотеки одновременно на нескольких устройствах. Перед работой убедитесь, что облачный сервис завершил синхронизацию.
