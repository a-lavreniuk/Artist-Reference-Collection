# Карточки

Карточка — основная единица работы с материалом в ARC. Она связывает физический файл с данными, которые нужны для организации и поиска.

\[скриншот: карточка в сетке библиотеки и её панель «Детали»]

## Что содержит карточка

Карточка представляет исходный файл и может содержать описание, метки, принадлежность к коллекциям, пользовательские поля и технические сведения о файле.

Карточка не является второй независимой копией изображения. Она представляет материал в каталоге ARC.

## Организация карточки

Добавляйте карточку в одну или несколько коллекций, назначайте метки и заполняйте пользовательские поля по мере необходимости. Эти действия меняют каталогизационные данные, а не визуальное содержимое исходного файла.

## Просмотр карточки

Откройте карточку, чтобы перейти к просмотру материала и панели «Детали». Оттуда доступны сведения о файле и организационные действия.

## Удаление

Перед удалением различайте удаление карточки из определённой коллекции и удаление самой карточки из библиотеки. Эти операции имеют разный смысл и могут по-разному влиять на связанный файл.

Если файл был перемещён или удалён вручную за пределами ARC, карточка может потерять доступ к своему исходнику.
