# Шаблоны

Шаблон определяет структуру отображения информации в панели «Детали». Он позволяет заранее настроить рабочее представление карточки и не собирать его заново для каждого материала.

Шаблон особенно полезен, если вы регулярно работаете с одним и тем же набором данных.

\[скриншот: настройки шаблона деталей]

## Что даёт шаблон

Вместо просмотра всех доступных свойств подряд можно вывести на первый план только те данные, которые нужны в конкретном рабочем процессе. Это не удаляет остальные данные карточки — шаблон меняет их представление.

## Настройка

Настройка шаблона выполняется в разделе «Настройки → Шаблон деталей». Выберите необходимые элементы и задайте их порядок в соответствии с рабочим процессом.

После сохранения новый порядок используется при просмотре деталей карточек.

## Связь с пользовательскими полями

Пользовательские поля и шаблон решают разные задачи. Поле хранит дополнительное значение, а шаблон определяет, как это значение показывается вместе с другими данными.

Поэтому сначала создайте необходимые поля, а затем включите их в удобное представление деталей.
