# Организация

Организация в ARC строится поверх файлов. Сам файл отвечает за физическое содержимое, а карточка и связанные с ней сущности — за каталогизацию и поиск.

Основные инструменты организации:

* **коллекции** — логические группы материалов;
* **разделы** — способ структурировать рабочее пространство и навигацию;
* **метки** — признаки, по которым материалы можно классифицировать и находить;
* **пользовательские поля** — дополнительные данные, которые не помещаются в стандартную структуру;
* **шаблоны** — заранее настроенное представление деталей карточки.

\[скриншот: раздел организации библиотеки]

## Главное правило

Не нужно пытаться повторить файловую систему средствами ARC. Папки на диске отвечают за физическое хранение, а коллекции, метки и поля — за смысловую организацию.

Один и тот же материал может одновременно относиться к нескольким коллекциям и иметь несколько меток. Это позволяет строить пересекающиеся классификации без копирования файла.

## Организация по мере роста библиотеки

На небольшой библиотеке достаточно нескольких понятных меток и коллекций. По мере роста можно добавить категории меток, пользовательские поля и шаблоны.

Лучше добавлять новую сущность только тогда, когда она решает конкретную задачу поиска или навигации. Если материал невозможно найти без сложной многоуровневой структуры, сначала проверьте, не проще ли использовать метку или фильтр.
