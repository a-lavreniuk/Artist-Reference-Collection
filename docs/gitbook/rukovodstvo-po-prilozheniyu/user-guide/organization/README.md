# Организация

Организация ARC разделяет физическое хранение файлов и логическую структуру библиотеки.

Файл определяет расположение материала на диске. Карточка представляет его в ARC. Коллекции и разделы объединяют карточки, а метки и пользовательские поля описывают их.
