# Руководство по приложению

Это руководство описывает работу с ARC — от первого запуска и импорта файлов до организации библиотеки, поиска и настройки приложения.

ARC предназначен для локального хранения и каталогизации визуальных материалов. Приложение работает с файлами на вашем компьютере, а карточки, коллекции, метки и пользовательские поля помогают организовать их внутри библиотеки.

Руководство построено по принципу «что я хочу сделать → где это сделать». Если вы впервые открыли ARC, начните с раздела «Начало работы». Если библиотека уже создана, переходите непосредственно к нужной функции.

## Основные разделы

* **Основы** — модель ARC и основные термины.
* **Начало работы** — установка, создание библиотеки, первый импорт и настройка AI-поиска.
* **Сбор материалов** — ручной импорт, браузерное расширение, автоматический импорт и скриншоты.
* **Организация** — коллекции, метки, карточки, пользовательские поля и шаблоны.
* **Поиск** — обычный поиск, AI-поиск, фильтры и работа с дубликатами.
* **Просмотр** — просмотр карточек, детали, метаданные, исходные файлы и видео.
* **Настройки** — все пользовательские настройки ARC.
* **Дополнительные возможности** — функции, которые не относятся к основному рабочему циклу.
* **Справка** — сообщения о проблемах, ответы на частые вопросы и сведения о приложении.

## Быстрый старт

**Мне нужно добавить референсы** → «Сбор материалов → Добавление файлов».

**Мне нужно собрать материалы из браузера** → «Сбор материалов → Браузерное расширение».

**Мне нужно автоматически добавлять новые файлы из папки** → «Сбор материалов → Автоматический импорт».

**Мне нужно найти референс по описанию** → «Поиск → AI-поиск → AI Семантика».

**Мне нужно найти изображения, похожие на конкретный файл** → «Поиск → AI-поиск → Похожие изображения».

**Мне нужно отобрать изображения по типу, размеру, дате или другим свойствам** → «Поиск → Фильтры».

**Мне нужно найти дубликаты** → «Поиск → Дубликаты».

**Мне нужно объединить материалы по проекту** → «Организация → Коллекции и разделы».

**Мне нужно описать содержимое карточки** → «Организация → Метки» или «Организация → Пользовательские поля».

**Мне нужно изменить внешний вид и поведение приложения** → «Настройки».

> Названия элементов интерфейса в руководстве приведены так, как они отображаются в ARC. Если функция зависит от настройки или предварительной подготовки библиотеки, это отдельно указано в инструкции.
