# Руководство по приложению

Это основное пользовательское руководство ARC. Здесь описаны ключевые сценарии: создание библиотеки, сбор материалов, организация, поиск, просмотр и настройка приложения.

Если вы впервые открыли ARC, начните с Начала работы. Если библиотека уже создана, переходите непосредственно к нужному разделу.

## Быстрый старт

| Что нужно сделать                   | Куда перейти    |
| ----------------------------------- | --------------- |
| Установить ARC и создать библиотеку | Начало работы   |
| Добавить изображения и видео        | Сбор материалов |
| Организовать материалы              | Организация     |
| Найти материал                      | Поиск           |
| Посмотреть карточку или файл        | Просмотр        |
| Изменить параметры приложения       | Настройки       |
| Решить проблему или найти ответ     | Справка         |

## Разделы

* Основы
* Начало работы
* Сбор материалов
* Организация
* Поиск
* Просмотр
* Настройки
* [Дополнительные возможности](dopolnitelnye-vozmozhnosti.md)
* Справка

> Названия элементов интерфейса в руководстве приведены так, как они отображаются в ARC. Если функция требует предварительной настройки, это отдельно указано в инструкции.
