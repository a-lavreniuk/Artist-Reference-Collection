# Поиск без AI

Поиск без AI использует обычные данные, доступные ARC без локальной AI-модели. Этот режим подходит, когда вы знаете название, метку или другой текстовый признак материала.

\[скриншот: обычный поиск с текстовым запросом]

## Когда использовать

Используйте обычный поиск, если запрос можно выразить через данные карточки или каталога. Например, можно искать материал по названию или использовать метки и фильтры для ограничения результатов.

Такой поиск не пытается понять смысл изображения. Запрос вроде «рыжеволосая девушка в голубом платье» не превращает обычный поиск в визуальный поиск: для такого сценария нужен режим «AI Семантика».

## Поиск по меткам

Метки позволяют сначала классифицировать материалы, а затем использовать эту классификацию для поиска. Чем последовательнее вы называете метки, тем предсказуемее будут результаты.

Если нужная карточка имеет несколько признаков, используйте комбинацию поиска и фильтров вместо создания большого количества почти одинаковых коллекций.

## Ограничения

Без AI ARC не анализирует визуальное содержание изображения. Два изображения могут выглядеть очень похоже, но обычный поиск не считает их одинаковыми только на основании внешнего вида.

Для визуального сходства используйте «Похожие изображения», а для поиска по смысловому описанию — «AI Семантику».
