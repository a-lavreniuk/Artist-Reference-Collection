# Дубликаты

ARC различает два сценария: точное совпадение файла и визуальное сходство материалов.

Точные дубликаты обрабатываются во время импорта. Визуально похожие материалы можно искать отдельно в разделе дубликатов с помощью настройки точности.

## Точные дубликаты при импорте

Если импортируемый файл полностью совпадает с уже существующим материалом, ARC открывает диалог с вариантами действия: пометить совпадение как не дубликат, заменить исходник из системы или не импортировать файл.

Это позволяет принять решение в момент добавления материала, а не обнаруживать лишнюю копию позже.

## Поиск визуально похожих материалов

Для уже существующей библиотеки используйте поиск дубликатов. ARC сравнивает материалы по визуальному представлению и группирует кандидатов на совпадение.

Настройка точности определяет, насколько близкими должны быть изображения, чтобы попасть в результаты. Более строгая настройка уменьшает число слабых совпадений, более мягкая расширяет выборку.

## Что делать с найденной парой

После проверки двух материалов выберите действие, соответствующее вашей задаче:

* **Не дубликаты** — сохранить оба материала как независимые.
* **Удалить один вариант** — убрать ненужный материал.
* **Объединить в одну карточку** — сохранить один общий объект карточки вместо двух вариантов.

Перед удалением убедитесь, что выбранный вариант действительно не нужен и что вы понимаете последствия для физического файла.

## Дубликаты и AI-поиск

Поиск дубликатов — отдельный сценарий. Он не является обычным AI-поиском по библиотеке и не предполагает режима «поиск внутри найденных дубликатов».
