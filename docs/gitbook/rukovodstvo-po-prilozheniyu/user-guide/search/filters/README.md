# Фильтры

Фильтры позволяют ограничить текущий набор карточек по формальным свойствам файла и сохранённым данным. В отличие от AI-поиска, фильтры не пытаются интерпретировать изображение по смыслу.

## Доступные фильтры

В текущей структуре документации ARC предусмотрены фильтры по типу файла, ссылке, размеру файла, длительности, соотношению сторон, описанию, дате добавления и разрешению. Набор доступных фильтров может зависеть от текущей версии приложения и настроек списка.

## Как пользоваться

Выберите нужный фильтр и задайте его условие. После применения в библиотеке останутся карточки, соответствующие заданным критериям.

Несколько фильтров можно использовать последовательно, чтобы получить более узкую выборку. Например, можно ограничить результаты изображениями определённого размера, а затем дополнительно выбрать диапазон даты добавления.

## Фильтры и поиск

Фильтры дополняют обычный поиск. Если текстовый запрос отвечает на вопрос «что искать по данным карточки», фильтр отвечает на вопрос «какие свойства должны иметь результаты».

## Пресеты

Если набор фильтров используется регулярно, его можно сохранить как пресет и повторно применять без ручной настройки каждого условия.
