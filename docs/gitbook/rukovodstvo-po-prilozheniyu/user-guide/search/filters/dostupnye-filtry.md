# Доступные фильтры

Набор фильтров зависит от данных и функций текущей версии ARC. Фильтры могут использовать коллекции, метки и другие свойства карточек.

Выбирайте фильтр по тому признаку, который нужно использовать для ограничения текущего набора результатов.
