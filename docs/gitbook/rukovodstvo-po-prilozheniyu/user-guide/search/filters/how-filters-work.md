# Как работают фильтры

Фильтр задаёт условие для текущего набора карточек. После применения ARC показывает только материалы, соответствующие этому условию.

\[скриншот: открытая панель фильтров с одним активным условием]

## Несколько условий

Несколько фильтров используются совместно, чтобы последовательно сузить выборку. Если результат стал пустым, проверьте активные условия: одно из них может исключать карточки, которые проходят остальные проверки.

## Сброс

Чтобы вернуться к исходному набору карточек, удалите активные условия или используйте предусмотренную команду сброса фильтров.

## Фильтр не меняет данные

Применение фильтра не изменяет карточки, файлы или метаданные. Оно влияет только на то, какие материалы отображаются в текущем представлении.

## Пресеты

Набор фильтров можно сохранить как пресет, если вам приходится регулярно повторять один и тот же запрос. Пресет сохраняет условия поиска, а не отдельную копию результатов.
