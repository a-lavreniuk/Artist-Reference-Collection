# Как работают фильтры

Фильтр ограничивает результаты поиска по заданному условию.

Фильтры можно использовать самостоятельно или вместе с поисковым запросом. При применении нескольких условий результат становится более узким: материал должен соответствовать применяемым условиям.

\[скриншот: панель фильтров с несколькими активными условиями]

Если нужно регулярно использовать одну и ту же комбинацию условий, сохраните её как пресет.
