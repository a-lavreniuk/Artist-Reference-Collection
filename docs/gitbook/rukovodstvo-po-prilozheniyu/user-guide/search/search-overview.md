# Как устроен поиск

Поиск в ARC нужен не только для нахождения файла по имени. В зависимости от выбранного режима можно искать по обычным данным каталога, использовать фильтры или обращаться к визуальному содержанию изображения через AI.

Основные режимы:

* **поиск без AI** — работает с доступными данным карточки и каталога;
* **AI Семантика** — поиск по текстовому описанию визуального содержания;
* **Похожие изображения** — поиск по визуальному сходству с изображением-образцом;
* **фильтры** — дополнительное ограничение набора результатов;
* **дубликаты** — отдельный поиск и обработка визуально похожих материалов.

## Общая логика

Сначала сформулируйте, что именно вы знаете о нужном материале. Если знаете имя или метку — используйте обычный поиск. Если знаете визуальное содержание — используйте AI Семантику. Если у вас есть конкретный референс-образец — используйте Похожие изображения.

После получения результатов их можно дополнительно сузить фильтрами.

## Почему разные режимы не следует смешивать

Обычный поиск и AI-поиск отвечают на разные вопросы. Текстовый поиск ищет совпадения в данных каталога, тогда как AI анализирует визуальное содержание и сопоставляет его с запросом.

AI-поиск также требует предварительной индексации библиотеки. Без индекса ARC не располагает данными, необходимыми для семантического или визуального сопоставления.
