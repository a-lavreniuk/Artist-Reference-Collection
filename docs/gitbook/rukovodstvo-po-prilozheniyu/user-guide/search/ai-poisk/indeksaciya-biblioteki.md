# Индексация библиотеки

Индексация — это подготовка библиотеки к AI-поиску. ARC последовательно анализирует изображения выбранной моделью и сохраняет результат рядом с исходными данными, чтобы затем быстро выполнять поиск.

## Когда нужна индексация

Индексация нужна после первоначальной настройки AI и после существенного изменения AI-конфигурации, например при смене модели.

Новые материалы, добавленные в библиотеку после индексации, также должны получить AI-представление, прежде чем они смогут полноценно участвовать в AI-поиске.

## Как запустить

Откройте настройки AI-поиска и запустите индексацию библиотеки. ARC покажет состояние обработки. Длительность зависит от количества материалов, выбранной модели и производительности компьютера.

Большая библиотека и тяжёлая модель могут потребовать значительного времени. При использовании CPU обработка обычно занимает больше времени, чем при использовании совместимого GPU.

## Где сохраняется результат

После индексации данные AI сохраняются в JSON-файле рядом с исходным материалом. Эти данные нужны ARC для последующего поиска и не заменяют сам файл изображения.

## Если индексация не завершилась

Проверьте сообщение ARC об ошибке и состояние конкретных файлов. Если проблема повторяется, сообщите о ней через форму обратной связи и приложите описание ситуации и версию ARC.

Без корректного индекса AI-движок не сможет выполнить поиск по библиотеке.
