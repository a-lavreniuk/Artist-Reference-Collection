# CPU и GPU

CPU и GPU — два способа выполнять выбранную AI-модель. Они не представляют собой разные режимы поиска и не меняют саму модель.

## CPU

CPU доступен практически на любом совместимом компьютере и не требует отдельной видеокарты. Основной недостаток — скорость. Особенно заметна разница при индексации большой библиотеки и использовании тяжёлых моделей.

## GPU

GPU может значительно ускорить AI-обработку, если компьютер поддерживает соответствующее аппаратное ускорение. На совместимых NVIDIA-видеокартах тяжёлые модели обычно работают существенно быстрее, чем на CPU.

## Что выбрать

Если важна максимальная скорость и GPU доступен, используйте GPU. Если совместимого GPU нет или вы хотите снизить нагрузку на видеокарту, используйте CPU.

Качество результата при прочих равных определяется моделью, а не тем, CPU или GPU используется для её выполнения. Переключение устройства не заменяет смену модели.

## Практический сценарий

Для первой индексации большой библиотеки разумно использовать GPU, если он доступен. Для небольших библиотек разница может быть менее заметна.

Если во время AI-обработки компьютер активно используется для других задач, учитывайте дополнительную нагрузку на выбранное устройство.
