# Похожие изображения

«Похожие изображения» использует изображение как поисковый запрос. Вместо текстового описания вы передаёте ARC конкретный визуальный пример, а приложение ищет близкие изображения в проиндексированной библиотеке.

\[скриншот: режим «Похожие изображения» с выбранным файлом]

## Как выполнить поиск

1. Откройте AI-поиск.
2. Выберите режим «Похожие изображения».
3. Укажите изображение, которое хотите использовать как пример.
4. Запустите поиск.
5. Оцените результаты и при необходимости измените точность поиска.

Запросом может быть файл, который уже находится вне ARC. Его содержимое используется для поиска; это не означает автоматического добавления файла в библиотеку.

## Что считается похожим

Модель сравнивает визуальное представление изображений. В зависимости от выбранной модели похожесть может учитывать общую композицию, объекты, сцену и другие визуальные признаки.

Похожесть не означает, что изображения являются копиями. Два кадра из одной сцены могут быть визуально близкими, хотя физически это разные файлы.

## Требования

Для работы режима нужна установленная модель и индекс библиотеки. Если библиотека не проиндексирована, ARC не сможет выполнить поиск по существующим изображениям.

Подробнее о выборе модели и подготовке индекса см. [Модели](modeli.md) и [Индексация библиотеки](indeksaciya-biblioteki.md).
