# AI-поиск

AI-поиск позволяет искать материалы по визуальному содержимому, а не только по сохранённым метаданным. ARC выполняет анализ локально с помощью установленной модели.

Доступны два основных режима: «AI Семантика» и «Похожие изображения».

## AI Семантика

Введите обычное описание того, что хотите найти. Например: «рыжеволосая девушка в голубом платье», «ночной город с неоновыми вывесками» или «интерьер с большим окном и деревянным столом».

ARC сопоставляет текстовый запрос с индексом изображений и возвращает наиболее близкие результаты.

Подробнее: [AI Семантика](ai-semantic.md).

## Похожие изображения

Загрузите изображение, которое будет использоваться как визуальный пример. ARC сравнит его с проиндексированными материалами и покажет похожие изображения.

Подробнее: [Похожие изображения](similar-images.md).

## Что требуется для работы

AI-поиск требует установленной модели и индекса библиотеки. Если индекс отсутствует, движок поиска не сможет обработать запрос.

Если AI-функция отображается в интерфейсе как недоступная, откройте настройки AI-поиска и проверьте состояние модели и индекса.

## AI работает локально

Для поиска не требуется отправлять изображения в удалённый AI-сервис. Анализ выполняется на компьютере пользователя установленной моделью. Скорость зависит от выбранной модели и того, выполняется ли обработка на CPU или GPU.
