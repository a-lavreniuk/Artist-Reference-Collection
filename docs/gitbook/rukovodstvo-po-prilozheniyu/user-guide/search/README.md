# Поиск

Поиск в ARC объединяет несколько способов работы с библиотекой. Для простых задач достаточно обычного поиска и фильтров; для поиска по содержанию изображения можно использовать AI.

## Основные способы

**Поиск без AI** использует данные, которые уже известны ARC: названия, метки, описания и другие доступные свойства карточек.

**AI Семантика** позволяет описать нужный материал словами. ARC сравнивает текстовый запрос с индексом изображений.

**Похожие изображения** принимает изображение как запрос и ищет визуально близкие материалы.

**Фильтры** позволяют ограничить результаты по формальным свойствам файла и карточки.

**Дубликаты** предназначены для отдельного поиска материалов, которые являются одинаковыми или визуально похожими.

## Поиск и организация

Поиск не изменяет карточки. Он временно ограничивает отображаемый набор материалов. Если результат поиска нужно использовать повторно, сохраните набор условий как пресет, если такая возможность доступна в текущей конфигурации ARC.

AI-поиск требует предварительной подготовки. Если модель не установлена или библиотека не проиндексирована, семантические режимы не смогут работать полноценно.
