# Основы

ARC (Artist Reference Collection) — локальное приложение для хранения, каталогизации и поиска визуальных материалов. Его задача — сделать большую коллекцию изображений и видео управляемой: материал остаётся доступным как обычный файл на компьютере, а ARC добавляет к нему удобный слой каталогизации.

ARC не заменяет файловый менеджер и не является графическим редактором. В приложении вы организуете библиотеку, описываете материалы, собираете логические подборки и находите нужные карточки. Сам исходный файл продолжает существовать в файловой системе.

## Философия ARC

ARC разделяет физическое хранение и логическую организацию.

Физическое хранение отвечает на вопрос «где находится файл на диске?». Логическая организация отвечает на вопросы «что это за материал?», «к какому проекту он относится?» и «как его найти позже?». Поэтому добавление карточки в коллекцию или назначение метки не требует создавать копию изображения.

Основные принципы:

* исходный материал остаётся файлом в файловой системе;
* карточка является представлением файла внутри ARC;
* коллекции группируют карточки по пользовательскому критерию;
* метки описывают свойства материалов;
* поиск объединяет обычный текстовый поиск, фильтры и AI-механики;
* AI-функции выполняются локально, если они включены и необходимые модели установлены.

## Как устроен ARC

Работа строится вокруг библиотеки. В неё импортируются поддерживаемые изображения и видео. После импорта ARC создаёт карточки и сохраняет необходимые данные для отображения и каталогизации.

Карточка может иметь метаданные, метки, пользовательские поля и связи с коллекциями. Эти данные позволяют работать с одной библиотекой разными способами, не меняя физическую структуру файлов.

Для поиска используются несколько уровней:

1. обычный поиск по доступным данным;
2. фильтры по свойствам файлов и карточек;
3. AI Семантика для поиска по смысловому описанию;
4. Похожие изображения для поиска визуально близких материалов;
5. отдельный поиск дубликатов.

Подробнее о каждом уровне — в разделе «Поиск».
