# Глоссарий

В ARC используются несколько терминов, которые описывают разные уровни работы с материалами. Важно различать физический файл, карточку и логическую организацию библиотеки: это не одно и то же.

**AI** — набор функций ARC, использующих локальные AI-модели для анализа изображений и поиска по их визуальному содержанию.

**AI Семантика** — режим AI-поиска, в котором запрос формулируется обычным текстом. ARC сопоставляет смысл запроса с визуальным содержанием проиндексированных изображений.

**Автоматический импорт** — функция, которая отслеживает выбранную папку и добавляет появившиеся в ней поддерживаемые файлы в библиотеку ARC.

**Автотегирование** — автоматическое добавление меток к материалам с использованием AI. Результат следует воспринимать как автоматическую классификацию, которую при необходимости можно исправить.

**Библиотека** — рабочее пространство ARC, связанное с определённой папкой на диске. В библиотеке ARC хранит рабочие копии импортированных файлов и данные, необходимые для их отображения и поиска.

**Браузерное расширение** — способ отправить материал из браузера в ARC. После передачи материал обрабатывается как обычный импорт.

**Дубликат** — повторный или практически совпадающий материал. ARC различает точные совпадения файлов и визуально похожие изображения.

**Индексация** — подготовка материалов библиотеки для AI-поиска. ARC анализирует изображения выбранной моделью и сохраняет результаты, необходимые для последующего поиска.

**Исходный файл** — физический файл изображения или видео. Карточка ARC представляет этот файл в библиотеке, но не заменяет сам файл в файловой системе.

**Карточка** — основная единица материала в ARC. Она объединяет исходный файл и связанные с ним данные: метки, коллекции, пользовательские поля и другие сведения.

**Коллекция** — логическая группа карточек, созданная пользователем по любому удобному критерию. Коллекция не обязана соответствовать отдельной папке на диске.

**Категория меток** — группа связанных меток, используемая для поддержания структуры классификации.

**Метаданные** — сведения о файле и карточке, которые описывают материал и помогают работать с ним. В зависимости от типа файла это могут быть технические параметры, имя, размер, дата и другие доступные сведения.

**Метка** — отдельный признак карточки. Метки используются для ручной классификации материалов и поиска по библиотеке.

**Модель** — AI-модель, которую ARC использует для анализа изображений и построения индекса. Модели отличаются размером, требованиями к оборудованию и качеством результатов.

**Похожие изображения** — режим AI-поиска, в котором пользователь предоставляет изображение-образец, а ARC ищет в библиотеке визуально близкие материалы.

**Пользовательское поле** — дополнительное поле данных, созданное пользователем для хранения информации, которой нет среди стандартных свойств карточки.

**Пресет** — сохранённый набор параметров, который позволяет повторно использовать заранее настроенную конфигурацию, например набор фильтров.

**Раздел** — элемент логической структуры ARC, используемый для разделения содержимого и навигации по нему. Раздел не меняет расположение файлов на диске.

**Файл** — физический объект в файловой системе: изображение или видео. Один файл имеет конкретное расположение на диске; ARC работает с ним через карточку.

**Фильтр** — условие, ограничивающее набор отображаемых карточек. Фильтры можно комбинировать, чтобы сузить результаты.

**Шаблон** — заранее настроенная структура панели деталей карточки. Шаблон определяет, какие поля и в каком порядке пользователь видит при работе с материалом.

### Как связаны основные понятия

Типичный рабочий путь выглядит так: пользователь импортирует **файл**, ARC создаёт для него **карточку**, после чего карточку можно добавить в **коллекцию**, назначить ей **метки** и заполнить **пользовательские поля**. Для поиска используются обычный поиск и **фильтры**, а после настройки AI — **AI Семантика** и **Похожие изображения**.

Коллекции, метки и пользовательские поля описывают материал на уровне каталога ARC. Они не являются заменой исходного файла и сами по себе не определяют его физическое расположение.
