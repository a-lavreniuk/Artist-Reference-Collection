# Что такое ARC

ARC (Artist Reference Collection) — локальное приложение для хранения, организации и поиска визуальных материалов. Оно помогает собрать референсы в единую библиотеку и работать с ними как с каталогом: добавлять файлы, описывать их метаданными, объединять в коллекции, назначать метки и находить нужные материалы обычным или AI-поиском.

ARC работает с файлами пользователя локально. Библиотека не является отдельным облачным хранилищем: ARC организует рабочую папку на диске и хранит рядом с исходными материалами данные, необходимые для каталога и поиска.

Основная единица работы — карточка. Карточка представляет файл внутри ARC и содержит сам материал вместе с информацией о нём: названием, расположением, метками, коллекциями, пользовательскими полями и другими доступными данными. Поэтому файл отвечает за физическое хранение материала, а карточка — за его представление и организацию внутри ARC.

ARC рассчитан на библиотеку, которая постепенно растёт. Материал можно сначала быстро сохранить, а затем вернуться к нему и добавить метки, коллекцию или дополнительные поля. По мере роста библиотеки обычный поиск дополняется фильтрами и AI-инструментами, которые позволяют искать не только по сохранённым данным, но и по визуальному содержанию.

## Что ARC делает с файлами

При импорте ARC добавляет материал в рабочую папку библиотеки и создаёт для него карточку. Исходный файл при этом может быть сохранён в исходном месте или удалён — действие выбирается в процессе импорта.

Если материал уже находится в библиотеке, ARC не должен создавать несколько независимых копий только из-за повторного импорта. Для точного совпадения приложение показывает отдельное окно с вариантами обработки существующего материала.

Работа с карточкой не заменяет работу с исходным файлом. Когда требуется использовать изображение или видео в другой программе, открыть его можно как обычный файл в файловой системе.

## Что ARC не делает

ARC не является графическим редактором и не предназначен для изменения содержимого изображения или видео. Его задача — хранить, классифицировать и находить материалы.

ARC также не предоставляет собственную облачную синхронизацию. Если папка библиотеки расположена в Google Drive, OneDrive, Яндекс Диске или другом сервисе, синхронизацией занимается сам сервис. ARC работает с файлами в указанной папке как с обычными локальными файлами.

## С чего начать

Если ARC установлен впервые, начните с создания или открытия библиотеки, затем импортируйте несколько материалов и проверьте работу карточек. После этого настройте способ организации библиотеки — коллекции, метки и пользовательские поля. AI-поиск можно подключить отдельно: для него требуется включить функцию, установить модель и проиндексировать библиотеку.
