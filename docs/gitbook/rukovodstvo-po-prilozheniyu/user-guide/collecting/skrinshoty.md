# Скриншоты

Встроенное создание скриншотов позволяет быстро сохранить визуальный материал непосредственно в библиотеку ARC, не проходя отдельный путь через файловый менеджер.

\[скриншот: интерфейс создания скриншота]

## Когда использовать скриншоты

Скриншоты подходят для материалов, которые существуют только как часть экрана: фрагменты веб-страниц, интерфейсов, изображений, референсов или отдельных областей рабочего процесса.

Если исходный файл уже доступен отдельно, предпочтительнее импортировать сам файл: это сохраняет исходное качество и доступные метаданные.

## Настройка

Параметры скриншотов находятся в отдельном разделе настроек. Там можно настроить поведение функции и место, куда сохраняются созданные снимки, в соответствии с доступными в текущей версии ARC параметрами.

## Создание снимка

Запустите команду скриншота и выделите нужную область экрана. После создания снимок передаётся в ARC как новый материал.

После появления карточки её можно организовать так же, как любой другой импортированный материал: добавить в коллекцию, назначить метки и заполнить пользовательские поля.
