# Сбор материалов

ARC поддерживает несколько способов добавления материалов в библиотеку. Выберите способ в зависимости от того, где находится нужный материал.

## Разделы

* [Добавление файлов](add-files.md) — импорт существующих изображений и видео.
* [Браузерное расширение](brauzernoe-rasshirenie.md) — сохранение материалов из браузера.
* [Автоматический импорт](avtomaticheskii-import.md) — автоматическое добавление файлов из отслеживаемых папок.
* [Скриншоты](skrinshoty.md) — быстрый сбор изображений с экрана.
