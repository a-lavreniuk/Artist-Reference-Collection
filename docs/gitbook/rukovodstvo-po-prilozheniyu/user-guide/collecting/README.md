# Сбор материалов

ARC поддерживает несколько способов добавления материалов в библиотеку. Они отличаются точкой входа, но приводят к одному результату: файл попадает в библиотеку и становится доступен как карточка.

Основные способы сбора:

* ручное добавление файлов;
* браузерное расширение;
* автоматический импорт из отслеживаемых папок;
* создание скриншотов.

Выбирайте способ по источнику материала. Для уже существующих файлов удобнее ручной импорт, для постоянного потока из папки — автоматический импорт, для материалов из браузера — расширение.

## Что происходит после добавления

ARC проверяет импортируемый материал, переносит его в рабочую папку библиотеки и создаёт карточку. Далее карточку можно организовать с помощью коллекций, меток и пользовательских полей.

Если ARC обнаруживает точное совпадение с уже существующим материалом, приложение не должно молча создавать ещё одну копию: пользователь получает отдельный диалог с вариантами обработки совпадения.
