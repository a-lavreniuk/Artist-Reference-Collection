# Автоматический импорт

Автоматический импорт позволяет ARC следить за выбранной папкой и автоматически добавлять в библиотеку новые поддерживаемые файлы.

Это удобно, если материалы регулярно появляются в одной папке: например, туда сохраняются изображения из другого приложения, выгрузки или собранные референсы.

## Как работает автоматический импорт

Пользователь указывает отслеживаемую папку и включает автоматический импорт. Когда в ней появляется новый поддерживаемый материал, ARC обнаруживает файл и передаёт его в обычный механизм импорта.

Это означает, что для автоматического импорта применяются те же основные правила, что и для ручного добавления: материал копируется в библиотеку, создаётся карточка, а обнаруженные совпадения обрабатываются по правилам импорта.

## Что важно учитывать

Автоматический импорт не синхронизирует исходную папку с библиотекой. Он только отслеживает появление файлов и добавляет их в ARC.

После импорта в библиотеке появляется собственная копия файла. Поэтому удаление исходника или изменение файла вне библиотеки не следует воспринимать как редактирование карточки ARC.

## Настройка

Параметры автоматического импорта находятся в «Настройки → Автоматический импорт». Добавьте нужную папку и включите функцию.

Если материалов несколько, можно настроить несколько источников, если это поддерживается текущей конфигурацией приложения.

## Когда автоматический импорт лучше не использовать

Не стоит отслеживать папку с очень большим количеством временных файлов, кэшей или материалов, которые не предназначены для библиотеки. ARC будет воспринимать появляющиеся поддерживаемые файлы как кандидаты на импорт.

Для разовой подборки обычно проще использовать ручной импорт.
