# Добавление файлов

Ручной импорт предназначен для файлов, которые уже находятся на компьютере. Добавить материал можно через интерфейс ARC или перетащив поддерживаемые файлы в окно приложения.

\[скриншот: область библиотеки, в которую можно перетащить файл]

## Что происходит при импорте

После добавления ARC принимает исходный файл, проверяет его и копирует в рабочую папку активной библиотеки. На основе импортированного файла создаётся карточка.

Исходный файл в папке, из которой выполнялся импорт, при этом остаётся отдельным физическим объектом до тех пор, пока пользователь не выберет дальнейшее действие.

После успешного копирования ARC предлагает удалить исходный файл или оставить его на прежнем месте. Выбирайте удаление только в том случае, если копия в библиотеке действительно должна стать единственным экземпляром материала.

## Точные дубликаты

Если импортируемый файл является точным совпадением уже находящегося в библиотеке материала, ARC показывает отдельное окно обработки дубликата.

В нём доступны варианты:

* **Пометить как не дубликат** — продолжить импорт, если совпадение ошибочно определено как дубликат;
* **Заменить исходник из системы** — использовать импортируемый вариант как источник для существующего материала;
* **Не импортировать** — отменить добавление совпадающего файла.

\[скриншот: окно обработки точного дубликата]

## Массовый импорт

При добавлении нескольких файлов ARC обрабатывает их как одну операцию импорта, при этом отдельные файлы могут потребовать дополнительного решения, если для них обнаружено совпадение.

Для большого объёма материалов лучше сначала проверить импорт на небольшой группе файлов: это позволяет убедиться, что выбранная библиотека и политика обработки исходников соответствуют вашему рабочему процессу.

## Поддерживаемые форматы

ARC предназначен прежде всего для распространённых форматов изображений и видео. Если конкретный файл не принимается, проверьте его формат и кодек, а также сообщение приложения. Не переименовывайте расширение файла вручную в попытке сделать неподдерживаемый формат поддерживаемым: расширение не меняет внутренний формат данных.
