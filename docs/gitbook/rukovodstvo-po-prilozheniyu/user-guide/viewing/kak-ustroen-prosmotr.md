# Как устроен просмотр

ARC позволяет просматривать материалы внутри интерфейса, в полноэкранном режиме и в отдельном окне.

Просмотр не изменяет исходный файл. Он предоставляет интерфейс для просмотра материала и работы с его карточкой.
