# Метаданные

Метаданные — это сведения о файле и карточке, которые помогают понять свойства материала и использовать их при организации и поиске.

\[скриншот: блок метаданных в панели «Детали»]

## Что относится к метаданным

К техническим сведениям могут относиться свойства самого файла: формат, размер, разрешение и другие характеристики, которые доступны ARC для конкретного типа материала.

Часть данных относится непосредственно к карточке и её организации. Точный набор полей зависит от текущей версии приложения и типа файла.

## Метаданные и пользовательские данные

Технические свойства файла не следует смешивать с пользовательскими полями. Например, разрешение является свойством файла, а внутренний номер проекта — пользовательской информацией.

Такое разделение позволяет использовать технические параметры в фильтрах, а собственные сведения хранить в пользовательских полях.

## Изменение файла

Изменение исходного файла в другой программе может изменить его технические метаданные. Если это произошло, отображаемая информация в ARC зависит от того, когда и каким образом приложение обновляет данные карточки.
