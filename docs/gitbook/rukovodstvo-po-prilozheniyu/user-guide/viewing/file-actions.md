# Работа с файлами

Карточка ARC связана с физическим исходным файлом. Действия с файлом нужно отличать от действий с карточкой и её метаданными.

\[скриншот: меню действий с исходным файлом]

## Открыть исходный файл

Используйте доступную команду открытия файла, если нужно продолжить работу с материалом в другой программе. ARC передаёт управление исходным файлом, а не создаёт для этого отдельную копию.

## Открыть расположение

Если нужно понять, где физически хранится материал, используйте команду открытия расположения файла. Она полезна, когда требуется проверить файл в проводнике или выполнить операцию с папкой.

## Удаление

Удаление карточки и удаление физического файла — не обязательно одно и то же действие. Перед подтверждением внимательно прочитайте текст команды или диалога и убедитесь, что удаляется именно то, что вы хотите удалить.

Особенно осторожно работайте с материалами, которые используются в нескольких логических коллекциях: одна карточка может быть связана с несколькими группами.

## Файл и карточка

Если физический файл перемещён или удалён вне ARC, связь карточки с ним может перестать работать. При работе с файлами библиотеки по возможности используйте функции ARC, чтобы не нарушать ожидаемую структуру хранения.
