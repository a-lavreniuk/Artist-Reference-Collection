# Просмотр

Раздел «Просмотр» отвечает за работу с отдельной карточкой: открытие изображения или видео, переход между материалами, просмотр деталей и работу с исходным файлом.

\[скриншот: открытая карточка в режиме просмотра]

Карточка в ARC состоит из визуального содержимого и связанных данных. Просмотр позволяет сосредоточиться на самом материале, а панель «Детали» — работать с его описанием и организацией.

## Основные способы просмотра

Изображение или видео можно открыть поверх библиотеки в оверлее. При необходимости доступен полноэкранный режим. Отдельные сценарии позволяют открыть материал в отдельном окне.

В режиме просмотра можно переходить между карточками, не возвращаясь каждый раз к сетке библиотеки.

## Детали карточки

Панель «Детали» содержит информацию о текущем материале: метаданные, организационные сведения и пользовательские данные, если они настроены.

## Исходный файл

ARC хранит связь карточки с физическим файлом. Из просмотра можно выполнить доступные операции с файлом, например открыть его в системном проводнике или передать в другое приложение, если соответствующая команда предусмотрена интерфейсом.
