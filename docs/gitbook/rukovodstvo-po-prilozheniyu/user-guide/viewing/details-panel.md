# Панель «Детали»

Панель «Детали» содержит сведения о текущей карточке и инструменты работы с её данными. Это основной интерфейс для организации отдельного материала.

\[скриншот: открытая панель «Детали»]

В зависимости от структуры карточки здесь могут отображаться метаданные файла, описание, метки, пользовательские поля и другие доступные сведения.

## Работа с данными

Изменение данных карточки не изменяет пиксели изображения и не редактирует содержимое видео. Вы работаете с каталогизационной информацией, которую ARC хранит отдельно от содержимого файла.

## Метки

Используйте соответствующий блок панели для просмотра уже назначенных меток и добавления новых. Метки можно изменять по мере необходимости.

## Пользовательские поля

Если в библиотеке созданы пользовательские поля, их значения доступны в карточке в соответствии с настроенной структурой. Это позволяет хранить дополнительную информацию без использования имени файла или свободного описания.

## Метаданные

Метаданные позволяют посмотреть технические сведения о файле. Их состав зависит от самого материала и данных, которые ARC может получить из файла.
